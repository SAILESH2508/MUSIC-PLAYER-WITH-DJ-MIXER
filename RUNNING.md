# How to Run the Music App 🎵

Welcome to the Pro DJ Music App! Follow these steps to get the party started.

## Prerequisites
- **Python** (installed)
- **Node.js** (installed)

## 1. Start the Backend (Django)
This powers the database and API.

1. Open a terminal.
2. Navigate to the project folder:
   ```bash
   cd "c:/FULLSTACK PYTHON/django/django project/music"
   ```
3. Run the server:
   ```bash
   python manage.py runserver
   ```
   *Keep this terminal open!*

## 2. Start the Frontend (React)
This runs the beautiful UI.

1. Open a **new** terminal.
2. Navigate to the frontend folder:
   ```bash
   cd "c:/FULLSTACK PYTHON/django/django project/music/frontend"
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the link shown (usually `http://localhost:5173`) in your browser.

## 3. How to Use
- **Register/Login**: Create an account to start.
- **Play Music**: Use the cover flow to select songs.
- **DJ Panel**: Click the "🎧 DJ Panel" button in the top right.
    - **Sound Effects**: Click buttons for Airhorn, Scratch, etc.
    - **Speed**: Use the slider to speed up/slow down the song.
    - **Filter**: Use the slider to muffle the sound (Low-Pass).
    - **Party Mode**: Click for confetti!

## 4. Pro DJ Mode 🎛️
Want to mix like a pro?
1. Click **"🎛️ Go to Pro DJ Mode"** on the main screen.
2. **Dual Decks**: Load different songs into Deck A and Deck B.
3. **Crossfader**: Fade between tracks using the slider in the middle.
4. **EQ**: Tweak the Highs, Mids, and Lows for each deck.
5. **Looping**: Set loop points to extend the beat.

Enjoy! 🚀
